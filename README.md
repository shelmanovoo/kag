# kag

Knowledge Graph QA на Neo4j + OpenAI (OpenRouter)

Этот проект демонстрирует, как связать граф знаний на базе Neo4j с LLM-моделью через OpenRouter, чтобы отвечать на вопросы пользователя строго на основе знаний, извлечённых из графовой базы.

📌 Возможности
	•	Автоматическое извлечение контекста из Neo4j по имени сущности.
	•	Формирование структурированного контекста для LLM.
	•	Генерация ответа модели только на основе данных графа знаний (RAG over KG).
	•	Создание тестовых данных (Эйнштейн, Бор, основные теории).

📂 Структура проекта

project/
│── kag.py                # Основной код
│── .env                   # Переменные окружения
│── README.md              # Этот файл

⚙️ Требования
	•	Python 3.10+
	•	Neo4j 5.x
	•	Запущенный Neo4j по адресу: bolt://localhost:7687
	•	Аккаунт в OpenRouter

Установить зависимости:

pip install neo4j python-dotenv openai

🔧 Настройка окружения

Создай файл .env:

OPENROUTER_API_KEY=твой_api_ключ
NEO4J_PASSWORD=пароль_от_neo4j

▶️ Как запустить
	1.	Убедись, что Neo4j запущен.
	2.	Выполни:

python main.py

Скрипт:
	•	создаст тестовый граф знаний (если он отсутствует),
	•	выполнит запрос к графу,
	•	передаст контекст в LLM,
	•	выведет ответ в консоль.

🧠 Как работает

1. Создание графа знаний

В Neo4j автоматически создаются узлы:
	•	Albert Einstein
	•	Нильс Бор
	•	Специальная теория относительности
	•	Общая теория относительности
	•	Квантовая механика

и связи между ними:

Einstein —[РАЗРАБОТАЛ]→ Теории
Einstein —[ВЛИЯЛ_НА]→ Квантовая механика
Einstein —[СПОРИЛ_С]→ Бор
Бор —[РАЗРАБОТАЛ]→ Квантовая механика

2. Извлечение контекста

Запрос:

MATCH (n {name: $name})-[r]->(m)
RETURN ...

Конвертируется в строки:

Albert Einstein → РАЗРАБОТАЛ → Специальная теория относительности
...

3. Генерация ответа

Модель получает пример запроса:

Как Эйнштейн связан с квантовой теорией поля?

И отвечает только на основе предоставленного контекста.

📘 Пример вывода

Контекст из KG:
Из графа знаний известно:
Albert Einstein → ВЛИЯЛ_НА → Квантовая механика
Albert Einstein → СПОРИЛ_С → Нильс Бор
...

Ответ модели:
На основе предоставленных фактов из графа знаний я не могу ответить на вопрос о связи Эйнштейна с квантовой теорией поля, так как такой информации в графе нет. В графе есть только информация о связи Эйнштейна с квантовой механикой (он влиял на её развитие), но не с квантовой теорией поля.
